# 多言語対応

[English](../localization.md) · [日本語](localization.md)

画面の文章はCコードへ直接埋め込まず、意味を表す固定キーと `locales/en.json` / `ja.json` に分離しています。英語が原文です。名前・生態・技も翻訳キーを参照します。ビルド時にROMの定数テーブルへ変換するため、実機でJSONを読む必要はありません。

タイトル画面のSELECTで日本語／英語を切り替え、STARTでクレジット案内を開きます。新規ゲームは英語が標準です。保存形式v1の予約領域に言語を保存し、v0.1のセーブは日本語で復元します。日本語=0・英語=1の固定インデックスを変更してはいけません。

## 翻訳に参加する

1. JSONの値だけを編集し、意味キーを維持する。
2. `locales/context.json` の用途と最大文字セル数を確認する。
3. ゲームは英大文字とカタカナが基本。文章はそれぞれ自然な英語／日本語にする。
4. `python3 scripts/check_locales.py` と `make test && make` を実行する。
5. 実際の160×144画面を確認してPRに添付する。

技カードは6セル、名前8セル、生態18セル、画面の1行は20セルです。翻訳漏れ、余分なキー、空文字、未対応文字、文字数超過を自動検査します。文字数が収まっていても、画面での読みやすさのレビューは必要です。

JSON形式はWeblateの翻訳編集と連携できる形です。外部アカウント、Webhook、同期設定はまだ作っていません。[英語版の設定例](../localization.md)に手順を記載しています。

追加言語にはフォント、VRAM、ROM容量、画面配置、保存形式の検討が必要です。現在は日本語・英語の2言語をサポートします。README・貢献ガイド・仕様書には対応言語へのリンクを付け、翻訳と技術的な変更を一緒にレビューします。
