# 描画と透過

[English](../rendering.md) · [日本語](rendering.md)

v0.3は承認済みの画面案を反映。タイトル・探索・戦闘・訓練・技の組み替えで、背景の森に操作UIを重ねています。状態は小さなHUD、選択は木色／金色のメダルで示します。独自素材の編集元は `assets/ui-art.json` と `data/monsters/*.json` です。

モンスターと操作メダルは実際のGame Boy OBJスプライトを使用し、色番号0を透過します。8×16単位で変換し、敵は列順と各タイルを反転。画面切り替え時は40個すべてを隠して再配置します。戦闘の同一走査線は最大9個で、実機の上限10個以内です。

建物・木・橋・トレーナー・ロゴは `scripts/scene_codegen.py` で背景と合成し、0の画素には下の絵を残します。8×8タイルごとに実際の4色パレットで完全再現できるか検査し、色の近似はしません。文字の空白にも背景を残します。状態・メッセージの不透明パネルは意図的なUIです。HP用タイル254/255は文字合成から保護します。

通常ビルドはPython標準ライブラリのみ。JSONの元ドットを直接編集して再現できます。

`tests/transparency_test.py` は実際のエミュレーター画素を下層画像と比較し、6体を左右両向きで検査します。試験専用ROMも本番の描画関数を使用。透過検査では背景確認のためOBJ表示を一時無効化します。通しプレイと動画はゲームRAM変更なしのボタン操作です。

結果は `dist/alpha-verification.json`。通常ビルドで静的検査に戻るため、公開前は最後に透過テストを実行します。試験専用ROMと参照PPMは配布ROMに含めません。

構図は任天堂公式の[ふしぎのぼうし](https://www.nintendo.co.jp/event/e3/gbasoft/legendofzelda/index.html)、[黄金の太陽の戦闘](https://www.nintendo.co.jp/n08/agsj/sento/index.html)、[マリオ＆ルイージRPG](https://www.nintendo.co.jp/n08/a88j/game/index.html)を参考に、背景の連続性・小さな状態表示・場面に重なる操作アイコン・奥行きを研究しました。参考作品の画像素材は使用していません。
