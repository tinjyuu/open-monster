# Open Monster v0.1.0 — 初期試作

コミュニティが生み出した奇妙なモンスターを、自分の戦い方に育てるゲームの最初の試作です。

6種のモンスター、12技、訓練と技の組み替え、探索・スカウト、3人のCPUへの挑戦、SRAMセーブを収録しています。通常のモンスター追加はJSONとドット絵で行えます。アイデアだけで参加できるIssueテンプレートと共同制作手順も公開しています。

独自コード・設定・画像・フォントはMITライセンス。

PyBoy 2.6.1で、探索から3人の撃破までの操作、敗北からの復帰、スカウトと交代、セーブ再開と不正セーブ保護を検証済みです。7体目をゲーム本体の変更なしに追加したROMも検証しました。

**Chromatic / オリジナルGame Boy Color実機は未検証です。** 対応する書き込み可能・セーブ対応カートリッジを使用してください。試作のためグラフィックは簡素で、音楽・詳細アニメーション・通信対戦は未実装です。

ダウンロード: `open-monster.gbc`。64 KiB、GBC対応、MBC5 + RAM + battery。

操作: 十字キーで移動/選択、Aで決定、Bで戻る/戦闘メニュー、探索中STARTで保存。出発地点の建物の近くでAを押すと育成拠点に入れます。
